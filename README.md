A tiny, deterministic Python program that writes a single original dad joke to `/output/entry.txt`. The joke is the whole entry: a dad announces he is starting a band called The Leftovers, and the punchline lands on "covers" — cover songs, played only on Sundays, right after dinner, when leftovers exist.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.txt` (120 characters, UTF-8). No input, no network, no randomness: the same joke, byte for byte, on every run.
